# Student Placement Prediction Model Using Machine Learning

# Project Overview
This project predicts whether a student is likely to be placed based on their academic and other student-related details.

The project uses Machine Learning to train a model using a student placement dataset and then predicts the placement outcome for a new student.

# Technologies Used
1. Python

2. Streamlit

3. Pandas

4. Scikit-learn

5. Machine Learning

6. CSV Dataset
   
# Project Files

1. dataset.csv - Dataset used for training the model
2. train_model.py - Trains the Machine Learning model
3. placement_model.py - Contains the model logic
4. predict.py - Takes student details and predicts placement
5. .pkl file - Stores the trained Machine Learning model
